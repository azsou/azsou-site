<p>Replit 本身是老牌的在线 IDE，Replit Agent 则把它变成了「说一句话就能做出应用」的平台。智能体会规划功能、编写代码、配置运行环境和数据库，并在内置浏览器里测试，完成后直接用 Replit 的托管服务发布。</p>
<p>因为开发、运行、部署都在同一个云端环境里，它特别适合没有本地开发环境的人，或者想快速给团队做个小工具的场景。Plan 模式可以先讨论方案再动手，减少返工。</p>
<p>有免费模式可以体验，正式使用和更强的模型需要付费订阅；托管与部署按用量另计，大型项目要留意成本。</p>
