<p>Aider 是最早一批「在终端里和 AI 结对编程」的开源工具。你把需要修改的文件加入会话，用自然语言描述需求，它就会生成差异并直接写回文件，每次改动自动形成一条描述清晰的 Git 提交，回退非常方便。</p>
<p>它的特点是模型无关：可以接 OpenAI、Anthropic、Google、DeepSeek 等云端模型，也能通过 Ollama 等接入本地模型；内置的「仓库地图」会把项目结构压缩后提供给模型，在大仓库里也能找准位置。语音输入、自动跑 lint 与测试也是常用功能。</p>
<p>Aider 本身免费，费用来自你自己的模型 API。它更像一个精准的编辑工具，而不是全自动智能体，适合喜欢掌控每一步改动的开发者。</p>
