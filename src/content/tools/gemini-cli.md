<p>Gemini CLI 是 Google 以 Apache-2.0 开源的命令行智能体。它的工作方式和同类工具一致：在项目目录里对话，让它理解代码、生成修改、运行命令；不同之处在于它直接对接 Gemini 模型，并内置了 Google 搜索作为信息来源。</p>
<p>上手门槛低是它最大的优点：npm 一条命令安装，用个人 Google 账号授权就能使用免费额度，企业用户则可以接入 Code Assist 许可或 Google Cloud 项目。它同样支持 MCP 服务器、项目级说明文件和非交互模式，方便写进自动化脚本。</p>
<p>免费额度和可用模型会随 Google 的政策调整，正式项目建议关注官方说明；在国内网络环境下需要能访问 Google 服务。</p>
