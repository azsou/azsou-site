<p>GitHub Copilot 是很多人接触的第一个 AI 编程工具。如今它早已不只是自动补全：在 VS Code、Visual Studio、JetBrains 等编辑器里可以对话和使用智能体模式；在 GitHub 网站上可以让它审查 Pull Request、处理 Issue；Copilot CLI 则把同样的能力带进终端。</p>
<p>它的优势在于和 GitHub 的工作流天然打通——仓库、Issue、Actions、代码审查都在同一个账号体系里，团队管理和权限控制也比较成熟。模型方面可以在多家前沿模型之间切换。</p>
<p>Copilot 提供免费档，聊天与智能体用量有限；Pro 及以上档位按月订阅，学生和热门开源项目维护者有优惠政策（以官方说明为准）。</p>
