<p>扣子（Coze）是字节跳动的 AI 智能体开发平台，国内版为 coze.cn，国际版为 coze.com。它用可视化方式配置人设、知识库、插件和工作流，不会编程也能做出一个能查资料、写文案或处理表单的机器人。</p>
<p>它的优势在于分发：做好的智能体可以发布到豆包、飞书、微信公众号等渠道，或者通过 API 接入自己的产品。插件商店里有大量现成工具，工作流节点也支持写代码处理复杂逻辑。2025 年起，平台的核心开发套件以 Coze Studio 的名义在 GitHub 开源，可以私有化部署。</p>
<p>基础功能可以免费使用，高级模型与更高额度按套餐收费。在线平台的数据存放在字节跳动的服务上，涉及敏感数据时可考虑自部署的开源版本。</p>
