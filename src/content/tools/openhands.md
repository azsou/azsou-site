<p>OpenHands 起源于开源复刻 Devin 的社区项目 OpenDevin，如今是最活跃的开源编程智能体平台之一。它的智能体能在隔离环境中浏览代码、执行命令、编辑文件并跑测试，常被用来自动修复 Issue 或完成明确的小功能。</p>
<p>新版本的 Agent Canvas 把它变成了「智能体工作台」：默认运行 OpenHands 自己的智能体，也能通过 ACP 驱动 Claude Code、Codex、Gemini CLI 等第三方智能体，并在本地、远程服务器和云端之间切换后端。</p>
<p>代码以 MIT 协议开源，自部署免费（模型费用自理）；官方也提供托管的 OpenHands Cloud 和企业版。适合想自建 AI 开发流水线的团队。</p>
