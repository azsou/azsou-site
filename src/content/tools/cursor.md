<p>Cursor 是目前最受关注的 AI 编辑器之一。它在 VS Code 的基础上深度改造，把补全、对话和智能体放进同一个界面：写代码时 Tab 会预测你接下来要改的位置，选中代码可以直接用自然语言要求重写，复杂需求则交给 Agent 自动跨文件修改并运行命令。</p>
<p>因为底子是 VS Code，原有的快捷键、主题和大部分插件都能迁移过来，学习成本很低。它支持接入多家前沿模型，也提供项目规则文件、代码库索引和 MCP，用来让 AI 理解团队约定。</p>
<p>Cursor 有免费的入门档，但智能体请求等用量有限制；重度使用需要付费订阅。闭源软件，企业使用前请留意代码隐私相关设置。</p>
