<p>这场约 25 分钟的讲座同样来自 2025 年 5 月 22 日的 Code w/ Claude 大会，主讲人是 Anthropic 应用 AI 团队的 Hannah Moran 和 Christian Ryan。它面向刚开始在产品里调用大模型的开发者：不讲玄学技巧，而是演示一份提示词如何一步步变得更可靠。</p>
<p>这类入门课的核心通常是几件事：交代任务背景和角色、提供必要的参考资料、给出示例、要求按步骤思考，以及明确输出格式，让结果可以被程序直接解析。无论你用的是 Claude 还是其他模型，这些原则基本通用。视频简介只有主讲人信息，细节以讲座内容为准。</p>
<h3>看点</h3>
<ul><li>从粗糙到可靠：一份提示词的迭代过程。</li><li>背景、示例、步骤、输出格式各自的作用。</li><li>适用于各家大模型的通用原则。</li></ul>
