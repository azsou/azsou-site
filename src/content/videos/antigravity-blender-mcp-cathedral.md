<p>这支一分多钟的演示把本站两个主题连在了一起：AI 智能体和 3D 美术。演示者 Tiago Aragona 把 Google 的智能体开发平台 Antigravity 通过 Model Context Protocol 接到 Blender，然后只给一张平面概念图，让智能体自己在 Blender 里建模。按官方简介，模型前后跑了 45 轮迭代，逐步推断建筑几何、补上柱子的凹槽细节，并设置体积光。</p>
<p>对独立游戏开发者来说，这类演示的意义不在于「一键出资产」，而在于展示了 MCP 让 AI 直接操作专业软件的可能：智能体不是生成一张图，而是调用 Blender 本身的建模与灯光功能，结果是可以继续手工修改的工程文件。实际效果与可控性还需要自己上手验证。</p>
<h3>看点</h3>
<ul><li>用 MCP 把编程智能体接到 Blender 的思路。</li><li>「多轮迭代 + 视觉对比」的建模流程。</li><li>产出是可编辑的场景，而不是一张静态图。</li></ul>
