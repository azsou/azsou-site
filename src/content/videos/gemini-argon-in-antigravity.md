<p>这支一分多钟的短片是模型发布的配套演示：Google 把 Gemini 4 Argon 放进了自家的「智能体优先」开发平台 Antigravity。片中连做了四个小项目——3D 宝塔模型、赛车游戏、掌机造型的界面和在手机上跑的 3D 世界——节奏很快，适合当作能力概览。</p>
<p>按官方简介，Argon 先在 Antigravity 桌面应用和 CLI 中面向特定订阅用户推出，同时在 API 中提供。演示视频天然是挑选过的最佳结果，真实项目里的效果取决于需求复杂度和你给的约束；把它当作「AI 做游戏原型能走多远」的参照即可。</p>
<h3>看点</h3>
<ul><li>同一个平台里连续完成 3D 模型、游戏与界面原型。</li><li>Antigravity 的桌面应用、CLI 与 API 三种使用方式。</li><li>适合快速验证玩法点子的原型流程。</li></ul>
