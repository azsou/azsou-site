<p>过去要让 AI 操作虚幻引擎，只能靠社区插件，接口五花八门。这支四分钟的官方视频介绍的 Unreal MCP 是 Epic 自己支持的方案：它实现了开放的 MCP 标准，任何兼容 MCP 的智能体工具都能连上编辑器，调用各个编辑器模块公开出来的能力去修改项目。</p>
<p>对游戏开发者来说，这意味着「让 Claude Code / Cursor 之类的工具帮我批量摆放资产、改蓝图参数、跑 PCG 流程」有了官方通道。视频简介里附带了文档、在 UE 与 UEFN 中连接 MCP 的教程，以及结合 City Sample 的 PCG + MCP 工作流示例，想动手的读者可以从那里继续。</p>
<h3>看点</h3>
<ul><li>官方支持 vs 社区插件：协议统一、能力由编辑器自己暴露。</li><li>可以直接用现成的智能体编程工具，也能自建集成与技能。</li><li>与 PCG 程序化生成结合的工作流方向。</li></ul>
