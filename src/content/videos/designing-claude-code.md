<p>大多数 AI 编程工具都在往 IDE 里塞功能，Claude Code 却反其道而行，把主战场放在终端。这期十二分钟的对谈由 Claude Code 团队的产品设计师 Meaghan Choi 讲述这个选择背后的考虑：终端几十年来几乎没变，但在大模型能读懂自然语言之后，它反而成了最轻、最通用的「对话窗口」。</p>
<p>视频的价值在于它讲的是<strong>设计决策</strong>而不是功能清单：如何让一个命令行工具既保持 Unix 式的可组合性，又让不熟悉终端的人也能上手；提示词输入框、权限确认、进度展示这些细节为什么这样设计。后半段对非工程背景的读者尤其有用——设计师可以直接用 Claude Code 做可运行的原型，而不只是静态稿。</p>
<h3>看点</h3>
<ul><li>「终端优先」的取舍：轻量、可脚本化、能嵌进任何现有工作流。</li><li>把「读代码 → 计划 → 修改 → 验证」的开发流程映射成对话步骤。</li><li>设计师用智能体编程做原型、评估工期、在新版本发布后快速调整细节的做法。</li></ul>
