## 测试分层与环境

- 静态/单元：schema、内容、令牌、类型、链接、安全头及体积。
- 数据库：真实隔离 PostgreSQL/PostgREST，验证 RLS、RPC、字段授权、迁移、事务、并发、审计与分页。
- 浏览器：Chromium/Firefox/WebKit，先跑现有回归，再补本清单。默认 E2E 中 Auth/Turnstile/OAuth/Storage/邮件有 mock，逐项标明。
- 真实集成：隔离 Supabase、授权测试收件箱、OAuth 应用和 Storage 桶。真实本地 PostgREST 测试不等于生产 Supabase 验收。
- 人工/真机：macOS Safari、iOS Safari、Android Chrome、Windows Edge/Firefox，VoiceOver/NVDA、输入法、软键盘、安全区与文件选择。
- 运维：隔离故障注入、调度、备份恢复、告警与版本回滚。生产演练必须另行批准。

没有真实服务或设备时对应结果为 BLOCKED，不是 PASS。I06/T051 只在 CMS 已启用或正式纳入交付时适用。
站长确认不纳入的项目可记 N/A，并保留原因、批准人、日期和替代流程；不把跳过计为通过。

## 路由与截图覆盖合同

B02 必须用实际 build 产物重新生成 manifest，而不是抄测试文件的抽样路径。

- 页面族包含：首页；应用/AI/游戏目录、分类、平台、详情和 `/go/` 中转；文章、视频、作品列表与详情；标签；搜索；关于、联系、法律、语言对应页。
- 动态流程包含：论坛列表/分类/有效与无效主题、用户页、登录注册回调找回、个人设置/收藏/通知、留言、友链、订阅确认与退订、错误与离线页。
- 后台包含：概览、内容、用户、用户详情、权限、官方内容、举报、留言、友链、订阅、审计、设置、数据导入导出。
- 明确区分 HTML、模板、运行时实例、API、feed、XML、重定向和只在非生产生成的 test kit；排除项写理由。
- 固定基线的 108 条源码记录、106 个源文件、98 项官方内容、78 个 `/go/` 平台组合和 120 个 tag 只是对账起点，不是最终 HTML 分母。
- 对每个实际 HTML 路由至少做一次结构/可访问性 smoke，并按桌面/手机、浅/深色拍首屏与 fullPage。
  动态无限实例用每个模板的明确合成种子状态覆盖，不声称穷尽未来所有用户内容。
- 空、加载、错误、无权限、有数据、长内容、离线、弹层、焦点、hover/active、选中/禁用等状态按组件和页面族补齐。

最低视口与环境矩阵：

- 全路由截图：1440×900、390×844，各浅/深色，首屏加整页。
- 关键模板与交互追加：320、360、768、1024、1920 CSS px 宽，短屏、844×390 横屏、安全区和软键盘。

- 角色：匿名、普通用户、封禁用户、版主、管理员，并测试登录后降权与会话过期。
- 真实设备记录具体型号、OS/浏览器版本和测试人。模拟视口、WebKit 引擎和真机结果分栏。

采图等待字体和图片稳定，分段滚动触发懒加载后回顶，再拍首屏和整页；弹窗/抽屉另拍。
