## 改了什么

- `isExpiryRejection(body)`：GoTrue 对过期与错签名**都**回 `bad_jwt`，只认 `msg` 明确是 `token is expired` / `token has expired` / `JWT expired`，且不含签名 / 畸形错误；取代 `/expired|bad_jwt/`。
- T046-4 需要三段证据：真实来源（iss = azsou-test、role authenticated）、**有效期内被接受**（`I01_EXPIRED_TOKEN_ACCEPTED_FILE`：`--capture-token` 在 exp 前写的 0600 记录，sha256 / sub / accepted_at < exp / 200 都要对上；缺 → 阻塞）、过期后因过期被拒（exp < now − 60 s）。
- `captureAcceptedToken` / `--capture-token=<0600 token 文件> --capture-out=<记录>`：只读、经用户直连通道；token 本身不落盘到记录里。
- `ChannelUnavailable`：用户直连网络错误 → 整个验收停止、记为阻塞，`summary.channel` 写明；不重试，不回退到管理 / 代理通道。
- 人工证据清单 T046-4 新增产物 `expired-token-lifecycle` 与观测 `expired_reason_is_expiry` = true、`accepted_before_exp_status` = 200（`manual-evidence.md`、`real-acceptance.md` 同步）。
