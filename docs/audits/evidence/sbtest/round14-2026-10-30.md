## 1. 修了什么（`scripts/sbtest/init-executor.mjs`）

- **受控文本按构造**：新增 `S` 标签模板、`F.*` 校验器、`safeText()` / `safeJSON()` / `controlled()`。`S` 的字面部分来自源码；插值只接受登记过的受控文本、整数、布尔值，其余（服务器正文、任意异常消息、URL、Location 主机……）一律变成 `[已隐藏]`。`F.*` 只放行格式 / 枚举 / 允许清单内的值：阶段、run / attempt id（`YYYYMMDDTHHMMSS-6 位十六进制`）、文件名（az_init / seed / 本进程钉住清单里的迁移名 / 合成 PNG / 合成账号）、合成邮箱、Postgres 版本数字、主机类别（不输出完整 URL / 主机名 / 凭据）、本机路径、错误码。
- **执行器异常**：`Refused` / `Uncertain` / `NotAdmitted` / `Unauthorized` / `Redirected` / 新 `HttpStatusError` 的消息必须是 `S` 拼出的受控文本，否则只剩 `[已隐藏]`；源码里不再有直接用字符串或普通模板构造这些异常的地方（单测扫描源码）。
- **原来拼服务器内容的地方**：`ro()` 非 2xx 只给状态码（正文读完丢弃）；`parseOneRow` / `parseChecked` / C0 / V1.cron 形状问题只给字段名、类型、行数；`classify401` 标签是固定文本（正文只用来分类）；准入原因、项目主机探测只给 `HTTP 401 [kind]` + 固定说明 / 受控错误码；3xx 只给状态码 + 同主机 / 跨主机（不记 Location 主机）；目标身份不符只说哪个字段不符；账号接管问题不回显运行标记 / 身份值；组织 id 只记「已返回」。
- **统一投影层**：正常 Markdown 运行记录、`executeNotes`、stdout JSON、兜底回执共用 `projectResult` / `projectInventory` / 请求记录路径形状（`pathOf`）/ `projectIdentity` / `projectC0`；`runRecordMarkdown` 每行由 `S` 拼成，最后每行再过一次 `safeText`。
- **errorCode() 允许清单**：只读真实 `Error` 对象的 `err.code`（undici「fetch failed」再看一层 `cause.code`，cause 也必须是 `Error`），在 `ERROR_CODES`（ENOENT、EACCES、EPERM、ENOSPC、EEXIST、EISDIR、ENOTDIR、EROFS、EMFILE、ENFILE、EBUSY、EIO、ELOOP、ENAMETOOLONG、EXDEV、EBADF、EDQUOT、执行器自己的 ESHORTWRITE、ECONNRESET、ECONNREFUSED、ECONNABORTED、ETIMEDOUT、EPIPE、ENOTFOUND、EAI_AGAIN、EHOSTUNREACH、ENETUNREACH、ENETDOWN、UND_ERR_*）内才返回，否则 `other`；执行器自己的错误类映射成 `redirect` / `unauthorized` / `http_status` / `uncertain_shape` / `timeout` / `refused`。**不再对任何文本跑正则**。结果里新增 `error_code` 字段（写入时就是受控码），回执只认它或第 ① 层 `http`。`transportCode` 也改成按类型 / 错误码判断（新 `ClientTimeout` 类作为 AbortController 的 reason）。请求记录的传输错误只记 `ERR:timeout` / `ERR:network`。
- **不改的**：退出码、阶段、已知结论、未知状态、写通道语义（第十三轮的 B0 / 迁移 / 种子 / Storage 规则原样）；C0、V1.cron 不动；plan / manifest 子命令（零网络、只打印本地清单）不在本轮范围。`redactText` 只作兼容保留，输出路径不再使用。
- 测试改动：`tests/unit/sbtest-init-r12.test.ts` / `sbtest-init-r13.test.ts` 里的 run / attempt id 从 `run-1` / `att-1` 换成真实格式（新规则只认 newAttemptId 格式）；r13「错误 → 受控错误码」用例改为给结构化 `error_code` / `http`（本轮要求不再从文本解析），`inventory.error` 状态类别随之为 `none`，`recordError` 改传异常对象。`tests/fixtures/sbtest/fs-fault.mjs` 新增 `record-esecret`（code = 清单外的 ESECRETDEMO42）。
