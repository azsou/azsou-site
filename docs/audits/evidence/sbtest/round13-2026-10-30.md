## 1. 修了什么（PR #5，`scripts/sbtest/init-executor.mjs`）

### A. 兜底回执：真正的逐层白名单

- `fallbackReceipt` 不再递归转储 `inventory`：每一层按允许的字段名 + 类型投影，不认识的字段（任意层）直接丢弃。
  - `results[]`：`file`（az_init / seed / 迁移文件名 / 合成 PNG / 合成账号，否则「格式不符，已隐藏」）、`outcome`（已知结论，否则 `other`）、`http`（第 ① 层）、`verification`（第 ② 层）、`verify`、`error`。
  - `error`：只输出受控错误码（`http_status` / `redirect` / `timeout` / `network` / `unauthorized` / `uncertain_shape` / 文件系统码 / `other`）+ 状态类别 + 阶段 + 端点；阶段 / 端点由文件种类推出，不取自由文本；**不输出服务器原始正文**。
  - `inventory.items`：只认 `ledger`（file / run_id / 哈希前缀）、`accounts`（合成邮箱 + 打码 id；非合成邮箱隐藏、未打码 id 重新打码）、`counts`（表名 → 非负整数）、`storage_objects`（打码对象名 + 大小）、`running_sessions`；`inventory.error` 与 `record_write_failure` 只给错误码。
- 新导出 `redactText(v, secrets, max)`：**先**在完整字符串上替换已知秘密值（长的先换，含 URL 编码形式），**再**按关键字打码（`password: v`、`key=v`、`"password" : "x"`、`'secret': 'a b'`、Bearer、JWT、sb_ 密钥、关键字后跟空格的值），**最后**截断——秘密跨截断点不留前缀。关键字只是第二层：回执本身已只投影白名单字段。
- 新导出 `errorCode(text)`（受控错误码）。

### B. 其余写通道的不确定性（只动 B0、Storage 上传、迁移 / 种子及其回执）

- 新增 `postSendHttp` / `httpText` / `transportCode`（第 ① 层，只有状态码 / 受控短码）。
- **B0**（新 `bootstrapLedger`）：2xx → 继续；4xx → 显式拒绝、未提交（1）；5xx / 其他非 2xx / 超时 / 断线 / 发出后 3xx → 只读查 `az_init.applied`：存在 → 已提交（C0 时不存在、B0 单事务），继续；不存在 → **不确定（3）**（B0 没有运行标记，不能排除仍在运行，不是「确定未提交」）；核对失败 → 3。修复前：5xx → 1（「未提交」），3xx → 2。
- **迁移 / 种子**（`runTx`）：发出后 3xx 不再抛成拒绝，和 5xx / 断线一样按账本 + 运行标记核对（只读端点，从不访问 Location 主机）；核对请求自身的 3xx / 401 / 形状 / 网络 → 无法核对（3），不当成拒绝。已提交 → 继续；确认未提交 → 1；仍在运行 / 无法核对 → 3。结果里不再保存服务器正文（修复前 `error` 带最多 300 字符原始正文）。
- **Storage 上传**（`uploadFiles`）：4xx → 显式拒绝（1）；5xx / 其他非 2xx / 超时 / 断线 / 发出后 3xx → 结果未知（3），立即停止，不重传 / 覆盖 / 删除。修复前：5xx → 1，3xx → 2。
- 逐项结果两层：`http`（① 原始状态）+ `verification`（② 结论 `committed` / `not-committed` / `still-running` / `unverifiable` / `not-verified` / `rejected` + 依据）；`outcome` = 业务结论。`executeNotes` 写成「结果 0005_… committed（HTTP 503；核对：committed，账本 1 行…）」。
- 测试变更：`tests/unit/sbtest-init-r7.test.ts`「同主机 307 也拒绝」一条按新语义改为「迁移写请求发出后 307：不跟随，按账本核对 → 未提交 exit 1，不发下一个文件」（第七轮的「不跟随」保留，「当成拒绝」被本轮要求取代）。
