## 1. 修了什么（PR #5，`scripts/sbtest/init-executor.mjs`）

1. **N = 0 只表示「本次没有成功写入任何交接行」。** 新增 `accountWriteEvidence(trace, results)` 与 `handoffConclusion(handoff, evidence)`：
   按本次请求记录里的 `POST /auth/v1/admin/users` / `PUT /auth/v1/admin/users/{id}` 及其状态（2xx 已生效 / 4xx 被拒 / 其余未知）+ 逐项结果下结论。
   - 没发过任何 Auth Admin 写请求（或全部 4xx）→ 才写「没有新建账号、没有改密，不需要 save_login」，空文件核对后删除；
   - 有请求结果未知（响应丢失 / 超时 / 3xx / 5xx）→ 「账号可能已创建 / 密码可能已被改，状态未知，需人工核对」，文件保留；
   - 建号 / 改密 2xx 但交接文件写入失败 → **交接错误**，列出账号与错误码，文件保留作证据；`createUsers` / `rotateAdopted` 在这一个账号上立即停下（不建下一个、不改密、不重试），结果记 `created-handoff-write-failed` / `password-set-handoff-write-failed`，退出码 3；
   - 没有执行证据 → 不下「没有建号」的结论，文件保留。
     `finishHandoff(handoff, evidence)` 保留为兼容形状（只返回说明行），从不抛异常。
2. **交接 / 清理错误不掩盖原执行结果。** `main` 里交接结论与运行记录写入都兜底：收尾错误写进运行记录单独一节「交接与收尾（与执行结论分开记录）」，原结论 / 阶段 / 逐项结果 / 清点不变。
   退出码：原 1 / 2 / 3 一律原样保留（3 绝不降成 1 或 0）；原成功 + 必需收尾失败 → 新增 **4（`EXIT.INCOMPLETE`）**——执行成功但收尾未完成，云端写操作不需要也不得重跑。收尾失败从不自动重试任何写操作。
   退出码含义表 `EXIT_MEANING` 同时写进运行记录末行；文档 ops/SBTEST-INIT.md §10.1。

## 2. 回归（`tests/unit/sbtest-init-r11.test.ts`，9 个用例）

- 纯逻辑 5 个（vitest 默认 5s，单个最长约 5 ms）：没有 Auth Admin 写请求 → 可以写没建号并删空文件；没有证据 → 不下结论、保留；ERR / 504 → 可能已创建、状态未知；200 + 交接写入失败 → 交接错误、保留；全部 422 → 按响应未建、删空文件。
- 真实本机 CLI 4 个：起子进程 `node scripts/sbtest/init-executor.mjs execute --mode env-token …`，基址指向本测试进程里的回环 HTTP 服务器（把共用的 `fakeApi` 合成状态挂到 `127.0.0.1:<随机端口>`），文件系统故障用 `node --import tests/fixtures/sbtest/fs-fault.mjs` 预加载注入（只对指定文件名的交接文件生效；执行器本身没有测试后门）：
  1. 建号响应丢失（服务器已建号后掐断连接）→ exit 3；运行记录与输出写「可能已创建 … 需人工核对」，不写「没有新建账号」；只发 1 次建号（不重试）；交接文件保留。
  2. 建号成功后交接写入失败（注入 ENOSPC）→ exit 3；交接错误列 `sbtest-admin@example.com` 与 ENOSPC；只建 1 个、0 次改密；交接文件保留且仍是 0600。
  3. 原执行成功（续跑只补文件）+ 空交接文件删除失败（注入 EACCES）→ **exit 4**；运行记录保留「结论：成功（V1 全部通过）」「阶段：V1」，收尾错误单列；每个文件只传一次。
  4. 原执行不确定（上传响应丢失）+ 空交接文件删除失败 → **仍 exit 3**；运行记录保留「结论：不确定」「阶段：F1」「清点（unknown）」，收尾错误单列；只上传 1 次（不重试）。
     这 4 个用例各自按用例 30s（`SPAWN_TIMEOUT`）：每个起一个 node 子进程、经 CLI `main` 读钉住的 19 个迁移（再起 git 子进程），并经回环 HTTP 跑完整执行或续跑。
