## 0. 结论先行

第一轮抓的是「视觉一致性」（字阶、图标、卡片、轮播、断点）。第二轮把范围扩到**边缘视口、系统模式、文案、转化、图像资源、正文排版、系统页面与跨浏览器**，新增 **32 项**：**P0 × 4、P1 × 17、P2 × 11**。

最影响「像不像商业产品」的 4 件事（P0）：

1. **焦点环在 Windows 高对比 / 强制色模式下完全消失**，常规模式下对比度也只有约 2:1（WCAG 要求 3:1）——因为全站用 `box-shadow` 画焦点环并 `outline: none`。
2. **英文单词在窄屏被拦腰拆开**：Logo「AZ / Studi / o」、「FableMoti / on」、「S3 Candidat / e」——全局 `overflow-wrap: anywhere` 的副作用。
3. **全站反复出现「自我辩白」式文案**：「不伪造评分、下载量和用户数」「本站暂无足够的真实下载数据，不做热度排行」「概念图 · 非真实截图」——在可见文本里，「不伪造」出现 30 次、「真实」80 次、「测试环境」31 次。诚实是对的，但反复声明读起来像在防御，不像产品。
4. **应用详情页没有可用的主操作**：首屏主按钮是两个「即将推出」禁用胶囊，截图区是「概念图」，统计条是「— 暂无评分 / — 真实计数」。商店详情页最重要的一件事（获取 / 打开）做不到。

好消息：320 宽零溢出、整页缩放 200% 零溢出、减少动态零位移、三引擎都无横向溢出、`backdrop-filter` 三引擎一致；字号 90% 以上用 rem，文字放大不会破版。

## 6. Top 15（给决策者看的）

1. 强制色模式焦点环消失、常规模式焦点对比 2:1（N-A11Y-1）
2. 窄屏英文单词被拆：「Studi/o」「FableMoti/on」（N-RWD-1）
3. 「不伪造…」类自我辩白 30+ 处（N-COPY-1）
4. 应用详情主按钮全是「即将推出」、截图是概念图（N-CVR-1）
5. Markdown 引用 / 表格 / 行内代码 / 脚注全无样式，h3 比正文小（N-PROSE-2）
6. OG 图：只有文章有专属图，应用图 16:9 无文字，三套视觉（N-IMG-1）
7. `/en/` 首页一整块中文标题、导航与中文版不一致、日期 ISO（N-I18N-1）
8. 搜索排名与摘要：视频压过同名工具，摘要里混入按钮文字（N-SRCH-1）
9. 强制色下按钮 / 输入框 / 胶囊失形（N-A11Y-2）
10. 宽屏 53% 空白 + 货架在屏幕中部硬切（N-WIDE-1）
11. 首页 12 个区块、首屏无内容型主 CTA，游戏详情无「试玩」（N-IA-1）
12. 订阅确认邮件是 4 个裸段落，缺一键退订头（N-MAIL-1）
13. 裂图无兜底、alt「XX 图标」重复朗读（N-IMG-2）
14. 触屏粘滞悬停（48 条 hover 只有 4 条加了 hover 媒体查询）+ 无 tap 高亮处理（N-TOUCH-1）
15. 术语四套名字（应用 / 应用商店 / 应用目录 / 自研应用）+ 引号「」“”混用（N-COPY-2）
