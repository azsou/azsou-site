# 原创文章计划（P8 T8.1）

目标：AdSense 申请前，站内有 **25–30 篇原创长文**（每篇 ≥ 1500 汉字），全部来自作者自己的项目与实际经验，不写泛泛的「十大工具」类内容。
已有 12 篇 V72 迁移文章偏短（约 300–700 字），保留并逐步扩写；本计划列出的是新写或重写的长文。

写作规则（与 [编辑规范](/editorial/) 一致）：

- 只写自己做过、测过的；数字只写自己测出来、并写明测试环境的，**不引用查不到出处的统计**。
- 引用官方政策 / 文档时链接原文，写清「截至哪天」。
- 每篇至少 3 个站内链接（相关应用 / 工具 / 文章），文末给下一篇可读的文章。
- frontmatter 写 `description`（40–160 字）、`toc` 与 `a-sec-N` 锚点一一对应；有联盟链接时写 `disclosure` 与 `sponsoredLinks`。
- 正文 ≥ 1500 字的文章自动获得文内 / 侧栏广告位（`src/lib/ads.ts` 的 `MIN_AD_ARTICLE_CHARS`）；短文不出广告。

**薄页面（文字少，但属于导航性质，保持收录，不放广告）**

| 页面                                                                  | 原因                           | 处理                                                    |
| --------------------------------------------------------------------- | ------------------------------ | ------------------------------------------------------- |
| `/u/`、`/forum/t/`（无参数）                                          | 客户端渲染外壳                 | 找不到数据时脚本写入 noindex（既有逻辑）；不放广告      |
| `/forum/meta/`、`/forum/product/`、`/forum/announce/`、`/forum/tech/` | 种子主题少，数据库主题动态加载 | 保持收录（社区增长后自然充实）；不放广告                |
| `/apps/category/*`、`/apps/platform/*`（1–2 个应用）                  | 分类下应用少                   | 待办：给每个分类加 100–200 字的原创导语；不放广告       |
| 只有 2 个条目的标签页（如 `/tags/single-file/`、`/tags/video/`）      | 条目少                         | 1 个条目的标签页已 noindex；2 个的保留；不放广告        |
| 12 篇 V72 短文（300–700 字）                                          | 正文短                         | 保持收录；计划表里 4 篇扩写，其余逐步扩写；短文不出广告 |

广告只出现在 `AdSlot` 预留的位置（长文正文 / 侧栏、文章列表），加载器在没有广告位的页面不会加载 AdSense，所以以上薄页面都不会出现广告。**不要在 AdSense 后台开启「自动广告」**，否则 Google 会把广告插到这些页面上。
