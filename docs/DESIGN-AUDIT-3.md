## 0. 结论先行

- **前两轮的 P0 全部关闭**：焦点环（强制色下可见，`outline 2px` 543 处、`box-shadow` 画法 600 → 0 主路径）、英文单词被拆、自我辩白文案（「不伪造」30 → 1，只留在关于页）、应用详情无主操作（现在是单个「上线时通知我」主按钮 + 平台 meta）、字号 20 → 10 档、字重 7 → 3 档、10 / 11px 文字 272 → 0、OG 默认图 27 / 30 页 → 0。
- **本轮新发现 1 个 P1 并已修复**：论坛编辑器在 390 宽把文档撑宽 74 / 70 px（A3-1，第一轮就有、一直被当成「后台表格」的同类问题漏掉）。现在 255 组测量里横向溢出 **0**。
