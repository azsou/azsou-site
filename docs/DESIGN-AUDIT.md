# AZ Studio v2 · 商业级 UI/UX 设计审计

> 审计对象：`v2/astro` 分支 head `0f10f02`（预览 https://azsou-site-git-v2-astro-azsous-projects.vercel.app ）
> 审计日期：2026-10-25 · 方法：本地 `npm run build` + Playwright（Chromium，本地 Postgres + PostgREST 种子数据，与 e2e 相同）
> 只做分析与方案，**没有改任何 `src/` 代码**。配套文档：[DESIGN-SYSTEM.md](./DESIGN-SYSTEM.md)（统一标准）、[DESIGN-QA.md](./DESIGN-QA.md)（测试规范）、[PLAN.md](./PLAN.md) §P9（任务清单）。

## 0. 结论先行

站点的**工程底子是商业级的**（Lighthouse 100、axe 0 违规、CLS 0、严格 CSP、深浅色、无障碍焦点环、悬停只用 transform），但**视觉层没有一套被强制执行的设计规范**：设计 token 已经存在，却只管了「值」，没有管「组合」——同一页面里出现 18 种字号×字重组合、10 个断点、4 种卡片高度、3 种图标底色；内容长度没有按卡片规格约束，导致截断、参差和大块留白。用户感受到的「离商业交付还很远」，主要来自这三类问题：

1. **图标与图片不统一**（第三方 logo 白底 / 黑底 / 彩底混杂，主体占画面 41%～90% 不等，游戏用「EM」「地牢」文字占位）；
2. **内容长度与卡片规格脱节**（AI 工具简介 58～90 字、自研应用简介 15～39 字，被塞进同一种精选卡；副标题 10～29 字塞进 20 字宽的一行）；
3. **排版层级与布局规则过多且不收敛**（字号 20 种、字重 7 种（Windows 雅黑只有 2 种可用）、字距 17 种、断点 10 个；轮播每屏 2.31 / 3.53 / 3.75 / 4.29 张，卡片总是被切在半截）。

这些都可以**在代码里系统性解决**（约 70%），剩下 30% 需要专业设计资源（品牌与图标绘制、插画 / 封面视觉）。详见 §4。

**Windows 字重塌缩（重要）**：字体栈在 Windows 上中文落到微软雅黑，雅黑只有 Regular(400) 与 Bold(700)。CSS 字重匹配规则下 500→400、600/650/700/750/800 → 700。也就是说**站点的 6 级字重在用户的 Windows 机器上只剩「常规 / 粗」两级**，这正是用户截图里「到处都是粗体、层级糊在一起」的原因。苹方最重只到 Semibold(600)，750 / 800 在 Mac 上也是合成或回落。

**工程化工具建议（按性价比排序）**

1. **Token 单一来源**：现有 CSS 变量已够用，不必引入 Tailwind。用 **Style Dictionary 4**（`tokens/*.json` → `tokens.css` + `tokens.d.ts` + Decap 预览 CSS）生成，后台 / CMS / OG 图共用一份。若后续要接 Figma，用 Tokens Studio 同步同一 JSON。
2. **设计 lint**：`stylelint` + `stylelint-declaration-strict-value`（color / font-size / border-radius / box-shadow / z-index / transition 必须用 `var(--…)`）+ 自定义规则禁止 token 外 px（`stylelint-scales` 校验 4pt 网格）。
3. **组件目录**：Astro 组件用 **Storybook 8（`@storybook/html` + 预渲染）成本高**；建议轻量做法：仓库内 `/_kit/` 路由（只在 dev / preview 构建，noindex）逐个渲染每种卡片 × 真实最长 / 最短内容 × 深浅色 —— 本质就是 Ladle / Storybook 的「故事」，但零新依赖，并且直接成为视觉回归的基准页。
4. **视觉回归**：Playwright `toHaveScreenshot()`（已在用 Playwright），页面 × 4 宽度 × 2 主题，基线存仓库（Linux Docker 里生成，避免字体差异），`maxDiffPixelRatio 0.002`；动画关闭、时间冻结、懒加载图片等待完成。
5. **内容 lint**：zod schema 加字数上下限 + 自定义 `zhLength()`（全角计 1、半角计 0.5），CMS 字段 `hint` 显示同一限制。
