## 0. 结论先行

- 第 2 轮找到 **6 个真问题，都已修好**。其中 3 个是第 1 轮「以为修好、其实没生效」的：首页标题和搜索框不在同一条中线上；格子里的名称会被纵向居中，同一行高低不齐；元数据有时和类型徽标同一行，有时换到下一行。
- 第 2 轮新发现并修好：AI / 应用详情页平台多（≥ 3 个）时操作卡很高，左侧指标条被推到中间，留下约 130px 空白；后台数字列（举报）表头没有和数字一起右对齐；后台页头说明文字贴着标题。
- 第 3 轮（§1.1）处理第 2 轮留下的问题：AI 详情操作卡下留白、后台设置单选组、「全选本页」位置、概览统计卡高低不齐、权限矩阵「可以 / 不可以」分不清、论坛首页分类大图占满首屏。顺带发现并修好：后台所有 `.badge--ok / --info / --danger` 一直被后写的 `.badge` 盖成灰色（同层同权重，后者覆盖），状态徽标颜色从未生效。
- **开发侧综合 8.7 / 10**（第 2 轮 8.6；各页见 §2）。前台主路径都在 8.5 以上；详情页 8.4–8.5，后台 8.5–8.7，论坛首页 8.6。仍未做的在 §3。

## 3. 仍未解决（如实列出）

1. AI 详情：设备识别出的主按钮不一定在第一位（换位会产生布局偏移，所以不换）；5 个平台的 Claude 页操作卡底仍比左栏低约 41px。
2. 论坛首页：390 首屏只到「全部主题」标题，第一条主题在折线以下；再紧凑需要把分类改成两列小卡或横滑，留到下一轮。
3. 后台：数据表单元格整体顶对齐（全站 `.table-wrap td` 规则覆盖了后台的居中），多行单元格旁的按钮看起来偏下；改它会动所有后台表格，本轮只修了权限矩阵。
4. 本轮没有在沙箱复测文字放大 200%（CI 的 modes 用例覆盖首页 / 列表 / 详情 / 文章）；axe 深色 / 强制色、布局、密度用例本地全部通过（341 个）。
5. 首页 390 宽格子按钮上方留白约 40px：网格各行等高，换来按钮全部落在同一条底线上，属于取舍。
